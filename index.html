9.14

VP CF Educational 191

C

题意

给你一个长度为 $n$ 的括号序列 $s$，可以通过删除 $s$ 中的最多 $k$ 个字符，最小化 $s$ 中最大合法括号子序列的长度。

$k \le n \le 5000$。

赛时思路

  1. 看完样例之后猜测，是不是一定先删 ( 再删 ) 呢？
  2. 考虑如何找到最大合法括号子序列。可以搞一个 $O(n^3)$ 的划分 dp，有没有更优的？想不出来。dp 不行就想贪心，贪心的时间复杂度通常比 dp 更优，感觉还是缺少那种，最优化问题想贪心想 dp 的直觉。
  3. 考虑这个最大合法括号子序列的结构是什么。最左侧一定是第一个 (，最右侧一定是最后一个 )。如果出现 () 的结构，那么它一定处于最大合法括号子序列中。
  4. 没啥好用的性质啊，放弃了，用时 $21$ 分钟。
  5. 想到一个诡异的贪心，首先剔除子序列开头的 ) 和结尾的 (，然后双指针找下一个 ( 和下一个 )，每次删除那个会使得距离缩小的更多的那个项。
  6. 首先明白，删除一个项至多减少 $1$ 对括号序列。按照上面那个做法贪心，只要右边不是 )，就能减少 $1$ 对。啊啊感觉还是不行啊，算了不管这题了。

正确思路

  1. 考虑如何找到最大合法括号子序列。括号序列的经典贪心是，遇到 ( 就取。我们按照这个贪心策略，遇到 ) 且 $sum > 0$ 就匹配，可以得到一个 $O(n)$ 的做法。
  2. 在这个做法的基础上进行删数。我们想让这个做法匹配到的括号最少，当遇到 ) 时，分类讨论一下：
    1. 若 $sum = 1$，则恰好有一个 ( 可以和它匹配，删除这个 ( 就可以减少一对括号。实际上这里需要用一个循环来删除，因为此时的 ( 都是一一对应的。
    2. 若 $sum > 1$，则此时不知道该删哪个好，于是我们就 延迟决策，先不管它。
  3. 这样的话序列最后会剩一段 $sum > 1$，左括号比较多，此时删除右括号就找不到另一个替换它，所以删右括号。删到前面的 $sum=1$ 段也没关系，一直删就好了。

D

题意

给你一个长度为 $n$ 的数组 $a$，你可以交换其中任意两个下标 $i,j$ 最多一次，问交换之后能不能使得序列中，相同的项都处于同一个块内。

$n \le 2\times 10^5,a_i \le 10^9$

赛时思路

  1. 按照值考虑，分类讨论一下：
    1. 如果有一个块，不用管。
    2. 如果有两个块，要么这两个块之间只有一个空隙（此时决定了一个交换的下标），要么有一个块只有一项（也决定了交换的一个下标）。
    3. 如果有三个块，要求其中两个块之间只有一个空隙，另一个块只有一项。此时两个交换下标都被确定了
    4. 好像没啥用啊。
  2. 操作一定选两个不同的数，所以最多管到两种值。我好像只要一次深搜出不来就基本出不来了，可能是心态上的问题，以后专门搞一个“回溯”训练吧。
  3. 没思路了，用时 $22$ 分钟。

正确思考

  1. 从操作本身的角度考虑。交换的数一定是未成功块的左右端点。这样的数很少，最多有 $12$ 个（101010），否则就无解了。
  2. 然后就是枚举这个下标，再枚举另一个下标，用一个 cnt 维护块数量，当 $cnt=种类数$ 时成功。

有关做题方法论的新思考

发表于 2026-09-11 分类于 方法论

猛猛训了五天 CF，感觉自己对于做题有了新的理解。

如果把解题的过程比作在一张图上找路径，那么经验就是你的启发式函数，方法论就是你的搜索策略。

某一题的思路秒出，是因为你的启发式函数足够强，强到无需考虑其它路径的可能，无意识地就得到了答案。这就是经验的力量，或者说是直觉。

同学评价 zak 做NOI题目的流程：

读读题目，观察一会；

想到若干个算法组合，发现思路正确；

写会代码，略微修改，AC；

身边其他同学做NOI题目流程：

读读题目，观察一会； 想到可能的算法；

仔细想想，发现假了；

突然想到一种可能的做法，但是非常复杂，犹豫啊；

写代码试试看，发现问题，有些细节要优化；

不知不觉时间不够了；

而且2-3的步骤经常会循环。。。

(引自知乎用户“未知的健忘”的回答)

这就是直觉的力量。我认为 zak 之所以能达到如此之高的水平，和他平时大量做题积累的经验和直觉是离不开的。别人还在想这样能不能做出来的时候，它已经知道这样做不了了。别人还在盲目尝试解法的时候，大量的经验形成的直觉告诉他：这样做是对的。所以他才能做的又快又好。

客观上讲，做不出一道题目的情况是不存在的。通过有意识地穷举所有路径，总能找到一条对的路径。所以大部分的“我做不出这题”是伪命题。

那为什么我们还会“卡题”呢？因为如果某个套路我们没见过，它的启发式函数值就特别低，低到你看都不会看。比如你从来不知道某个算法，那你在做题的时候就不会想着去用它。好在这是可以通过有意识地枚举来改变的。

做题的本质是更新启发式函数，以及增强自己的搜索意识。

讲了这么多理论，我们来讲点实际的东西。做一道题目的一般步骤是什么呢？

  1. 读题，看数据范围，看样例，考虑过程与边界。这一切都是为了让你对这个题目有大概的理解，然后才能激发你的直觉，也为方法论的实施做铺垫。
  2. 运气好的情况，你的直觉被激发出来了，记住你的直觉，这很宝贵。选一个你觉得最对的方向深入。
  3. 运气不好的情况，你读完题目还是一头雾水，蒙蒙的感觉。这个时候也不要怕，你的启发式函数没带给你任何东西，所以这时候只能摸黑走夜路。想想你的方法论，不断地尝试试错，直到你的方法论都不能带给你任何东西的时候，才宣布失败。
  4. 方法论-直觉 是可以交替进行的。
  5. 做出题目之后总结经验，优化方法论。

感觉 > 方法。

9.6 随心小记

发表于 2026-09-06 更新于 2026-09-11 分类于 随心小记

傍晚记

不得不承认，写题这件事情，并没有一个明确的，规律的方法论，存在的只是一些更为抽象的东西。

理性的算力实在是太过有限，不得不让位于感性。

或许我需要放下那些“规律的枷锁”，去拥抱“抽象的感性”吧。

写题本质上是一种启发式搜索，你的做题经验就是你的启发式函数。

你所做的一切努力都是在开拓知识网络，更新启发式函数。

去关注那些宏观的东西，例如：

  • 问题的形状
  • 明显的、特别的地方
  • 出题人的意图

而不是从单方面，单角度得从字眼中寻求突破。

这是不对的。

去拥抱模糊的，感性的美丽吧。

深夜记

我时常在入睡前感伤。

躺在床上，身旁是无尽的黑，内心里是激动、是恐惧、是自责、是担忧、是愧疚、是胆怯。

白天积攒的情绪会在黑夜时爆发出来，为了能让自己睡个好觉，我只得拼了命的忽略它们。

我隐约的感到有某个问题躲在黑夜里，一旦触碰，会非常痛苦，因而我选择逃避。

这个问题就是，“我做的对吗” “我做的好吗”。

尽管从他人口中得出了结论，但我无法轻易相信，也没有方法能够确凿的信任自己。

我像一只瞎了眼的豪猪，在无尽的夜里的无尽的林里乱窜。

我必须学会接受自己是个瞎子这个事实。

在人生尺度上，不确定性是不可避免的。

我需要学会闭着眼睛向前跑。

那些恐惧，那些怀疑只能用奔跑来缓解。

睡下吧，在这平凡而又特殊的夜。

我是多么幸运。
